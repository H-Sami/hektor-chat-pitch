## Facts and careful wording

- The [published schedule](https://hektormobil.se/kontakta-oss) is 08:00-17:00 on weekdays, excluding lunch 12:00-13:00: **40 staffed hours a week**, not 45. There are **128 hours outside those hours**. This does not show how many customers need help then.
- Forms and email can accept messages outside office hours. Do not say the contact form closes.
- The WiFi-calling example paraphrases Hektor's FAQ. The handover is illustrative, with no actual customer data.
- A cited answer can still be wrong. Review quality; do not promise zero mistakes.
- Customer-record access is outside the initial pilot. Even a general chat may receive personal information, so agree collection and retention rules before launch.
- Supplier billing without markup is a proposed commercial model. Implementation and support costs remain to be scoped.

## Likely questions

| Question | Response |
|---|---|
| What does it cost? | We need the initial scope and usage assumptions to quote implementation and running costs. The scoping discussion produces that proposal. |
| Will it replace support? | Support receives requests that need a person, with the relevant context. The pilot tests how helpful the general-answer service is. |
| What if an answer is wrong? | Use approved sources, test before launch and review sampled conversations. Define a correction and escalation process with Hektor. |
| Does it need our CRM? | The first pilot uses public information. Customer-record integration needs a separate feasibility and privacy review. |
| What happens when support is closed? | Explain availability and offer a follow-up request through the agreed process. Confirm the response promise with Hektor. |
| Can it run on our website? | We need to check the platform's embedding capability and access with the person who manages the site. |
| Can we switch model providers? | The proposal keeps the supplier relationship transparent. A change of provider requires testing and may need integration work. |

## Closing

“Can we set up a scoping discussion with your service owner and website contact? We will use your common questions to agree a focused pilot, its cost and how we will judge the result.”
